## Track B findings, mechanism

None.

**task253's decisive move, with the domain nouns stripped.** The count of units whose latent level lies below a fixed line, when each unit is seen only through averages of small, unequal samples, is the sum of each unit's probability of lying below it under the fitted noise model. Counting raw averages over-counts. Counting shrunken point estimates under-counts, because shrunken estimates are less spread than the levels they estimate.

**Path, in order.**
1. Parse three result extracts whose layouts drift, and keep the participating students.
2. Fit the filed three-level model by REML. This is R1, the default and the stump rung, which gives 28.
3. **Add up each unit's probability of lying below the line. This is R4, the decisive rung, which gives 42.**
4. The asks: the decisive probabilities carried to regional shares, students served and hub kilometres, on the census, directory, visit-plan and distance paths.

No build on file has this move at any rung (see Clean for the nearest).
