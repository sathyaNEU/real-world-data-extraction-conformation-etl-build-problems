# Start here: task numbers by lane

Every unbuilt seed in `analytical_tasks/` has a fixed task number, numbered objective by objective. A developer works the lane (block) assigned in their `.claude/authors/<handle>.md`, two builds at a time, lowest open number first, and starts one with `/build taskNN`. The folder is created at intake. Status is never edited here: it lives in `taskNN/pipeline.json`, and `python3 .claude/skills/build-pipeline/status.py` prints the board (`status.py taskNN` prints one seed).

A seed is an idea, not a design: keep its world, decision and quantity, and re-find the pitfall from the data (`stumping`). Read only the seed's header table and its Situation section. If the guard blocks a seed's driver, redraw inside the same objective and keep the number.
