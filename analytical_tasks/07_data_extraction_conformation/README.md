# Data Extraction & Conformation (ETL): 50 tasks (ET01 to ET50)

Each file is an ETL build blueprint on real, licence-clean public data. Unlike the stump notes in the other six folders, each one ships a written method memo that fixes the rules, and the difficulty is an honest-data trap in keys, grain, time semantics, crosswalks, units or supersession. Every file has the same twelve sections: the real-world project; the business decision; why it gets overlooked; the input package; the deterministic solution path; the traps; why the data is honest; a draft task prompt; deliverables; where 25+ rubric criteria come from; a golden-output checklist; and build notes. `analytical_tasks_index.csv` at the repository root carries the header fields for all 350 tasks; for these fifty it also fills `technique`, `trap` and `sources`.
